# 글 읽기와 목차

- 홈의 글 제목과 `전체 글 읽기`는 `/posts/<id>#post-start`로 이동합니다.
- 마이페이지의 내 포스트는 `tab=posts`, `category`, `post` 쿼리로 선택 상태를 유지합니다.
  목록·카테고리·글 이동을 브라우저 뒤로 가기와 새로고침에서도 복원할 수 있습니다.
- 홈, 전체 글, 카테고리 목록은 카드 외곽선 대신 글 사이 구분선을 사용합니다.
- 작성자 사진은 DB의 `User.image`를 사용합니다. 주소가 없거나 로딩에 실패하면 기본 아바타를 표시합니다.
- 데스크톱의 글 상세 왼쪽에는 작성자 프로필, 카테고리, 목차가 스크롤을 따라갑니다.
  모바일에서는 본문 위에 배치하며 긴 목차는 내부에서 스크롤할 수 있습니다.

글쓰기에서 `글에 목차 표시`를 선택하고 제목 단계를 정합니다.
본문의 서식 메뉴에서 `제목 1`, `제목 2`, `제목 3`을 적용하면 자동으로 목차에 추가됩니다.
작성 중 `목차 미리보기`에서 항목을 누르면 해당 제목을 편집할 수 있습니다.
글을 읽을 때 목차 항목은 해당 제목으로 이동하며, 현재 읽는 항목을 강조합니다.
동일한 제목이 반복되어도 각각 별도 이동 위치를 갖습니다.

표시 여부와 제목 단계는 본문 문서의 설정으로 저장되어 임시저장·발행·수정 시 유지됩니다.
기존 서식 글은 기본으로 모든 제목 단계를 표시하고, 제목이 없는 글에는 목차를 표시하지 않습니다.

검증: `node --experimental-strip-types --test tests/post-outline.test.mjs`.
전체 통합 검증: `npm run build` 후 `node --test tests/post-lifecycle.test.mjs`.
